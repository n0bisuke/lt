## 03:14 — 通常スライドの本文が上に寄る

- **問題:** `current-topic` 付きの箇条書きスライドで、本文が見出し直下に詰まっていた。
- **原因:** クラスなしスライドには縦中央配置があったが、`current-topic` を付けた通常スライドには適用されていなかった。
- **対応:** lecture テーマで通常スライドの本文を、見出し下の領域の縦中央に配置。
- **確認:** `npm run check` 成功。組み込みブラウザーで対象の3枚目を開いて内容を確認。

## 03:20 — キーメッセージの箇条書きが不揃い

- **問題:** キーメッセージの箇条書きがスライド中央に揃わず、各行の文字位置がばらついて見えた。

- **対応:** リストの幅を内容に合わせて中央配置し、リスト内の文字を左揃えに変更。部品の説明と例も更新。
- **確認:** `npm run check` 成功。15分版の HTML を再生成。

## 03:22 — メールエイリアス図がスライド枠からはみ出す

- **問題:** 図の左右と下側が切れ、ページ番号や下端の文字と重なって見えた。
- **原因:** 通常スライド内の単独画像に最大幅・最大高さの制約がなく、1920×1080 の SVG が 1280×720 のスライド枠を超えて表示されていた。
- **対応:** 通常スライドの単独画像を本文領域内に縮小し、縦横比を保って中央に配置。
- **確認:** `npm run check` と `git diff --check` 成功。15分版の HTML（32枚）を再生成し、組み込みブラウザーで対象の13枚目を開いて画像の代替テキストとページ番号を確認。ホストのブラウザーは使っていない。
