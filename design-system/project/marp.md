# Markdown で書く

スライドは `deck.md` に Marp の形式で書きます。1つのファイルから、オンラインのデッキ、記事、PDF ができます。`---` が次のスライド、`<!-- _class: 名前 -->` がそのスライドの型です。

## ファイルの先頭

```markdown
---
marp: true
theme: iotlt
title: エッジAIで焼肉の焼き加減判定やってみた
date: 2026-04-19
event: IoTLT vol134 in 潮風公園BBQ
eventUrl: https://iotlt.connpass.com/event/000000/
published: false
---
```

## 書き方

| 使う場面 | 書き方 |
| --- | --- |
| タイトル | `# 反応をみる MQTTも` |
| 箇条書き | `- 項目`（字下げで入れ子） |
| 太字 | `**大事な語句**` |
| 1枚に1か所のオチ（赤い下線） | `*今回のBBQで分厚い肉はたぶん無いので役不足*` |
| 今の段階（下線） | `<u>BBQの画像を探す</u> => モデル作成` |
| 下部の出典や補足 | `> 引用元: https://example.com/` |
| 本文いっぱいの画像 | `![](images/a.jpg)` |
| 横に並べた画像 | `![](images/a.jpg) ![](images/b.jpg)`（同じ行に書く） |
| 全面の写真 | `![bg](images/a.jpg)`、全体を見せるなら `![bg contain](images/a.jpg)` |
| コード | ` ``` ` で囲む。黒い箱に白文字になる |
| 表 | Markdown の表。短いコードは `` `noul` `` でチップになる |
| 画像の差し込み待ち | `<div class="lt-slot lt-label">写真: 何を入れるか</div>` |
| 記事にだけ出す文章 | `<!-- スライドには出さず、記事の本文になります -->` |

## スライドの型

| 型 | 使う場面 |
| --- | --- |
| `title` | 1枚目 |
| `profile` | 自己紹介 |
| `statement` | 1文だけで間を作る。SectionMarker もこれで書く |
| `stack` | 短い言葉を中央に数行 |
| `lines` | `=>` の比較や左揃えの説明 |
| `flow` | 文字と↓の処理の流れ |
| `split` | 画像と箇条書きを左右に並べる |
| `small` | 項目が多いときに本文を小さくする |
| `long` | タイトルが長いときに小さくする |
| `small-code` | コードの全文を見せる |

型は `<!-- _class: split small -->` のように組み合わせられます。重ねた画像（Collage）や機器とクラウドの図（Diagram）は Markdown で書けないので、各部品の README の HTML をそのまま貼ります。

## 記事の作られ方

スライドの内容の後に、発表者ノート（`<!-- -->`）が本文として続きます。記事としても読めるように、スライドごとに話す内容をノートに書きます。

- `title` と `profile` のスライドは記事に出ません。
- 同じタイトルのスライドを複製して段階的に見せた場合、記事には最後の1枚だけが出ます。
