# Lines

`=>` を使った比較や、文章での説明を左揃えで並べます。

**用意するもの：** 2〜5行。比較では、話の結論にあたる最後の行を `<b>` で太くします。`=>` はHTMLでは `=&gt;` と書きます。

```html
<section class="lt-slide">
  <h1 class="lt-title">マイクロスリープは判定が難しい</h1>
  <div class="lt-stage">
    <div class="lt-lines lt-body">
      <p>If/else =&gt; 割とむずい</p>
      <p>LLM =&gt; 判定が遅い。マイクロスリープ判定が厳しい</p>
      <p><b>Jev =&gt; 判定が早い。スマート！</b></p>
    </div>
  </div>
</section>
```
