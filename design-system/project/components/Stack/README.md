# Stack

短い言葉を中央揃えで数行並べ、ものごとを紹介するときに使います。

**用意するもの：** 2〜4行の短い言葉。`lt-title`（太字）か `lt-body` を選びます。

```html
<section class="lt-slide">
  <h1 class="lt-title">Jev</h1>
  <div class="lt-stage">
    <div class="lt-stack lt-title">
      <p>最近話題のスマート分類機</p>
      <p>爆速、安い、そこそこかしこ</p>
      <p>話さないLLM?</p>
    </div>
  </div>
</section>
```
