白い地に黒い文字を置き、今話す場所だけを濃くする、講演と研修のためのスライドの体系です。話題は選びません。LT 用の `iotlt` と並ぶ、講演用のテンプレートです。

もとは生成AI講座のために作ったデザインなので、生成AIの話で使う型（時代の比喩、人とAIの工程図、プロンプトの例）も残しています。ほかの話題では使わなくて構いません。

## 使い方

- スライドは Marp の Markdown（`decks/<名前>/deck.md`）で書き、先頭に `theme: lecture` を指定します。見本は `decks/sample_lecture/deck.md` です。
- 部品は `<!-- _class: 部品名 -->` で選びます。部品の一覧は `components.md` にあります。
- 書き方は `examples/<部品名>.md` を写します。
- スライドをAIに作らせるときは、先に `ai-authoring.md` を読ませます。

## 中心となる考え方

**1枚に1つのことだけを言います。** 主張は `key-message` で1文にし、くり返して覚えてもらいます。

**今話す場所だけを濃くします。** 目次や比較の再掲では、話していない項目を `ink-dim` に沈めます。長い話でも、聞き手が今どこにいるかを見失わないようにします。

**根拠を見せます。** 記事や資料は画面写真でなく `source-cards` や `link-cards` で、出典と日付を添えて示します。

**聞き手の次の行動で締めます。** 情報の紹介で終わらせず、`closing` で聞き手が持ち帰って試せることを1つ示します。

## 文章のルール

- 日本語の「です・ます」で、話しかけるように書きます。
- 主張はくり返して覚えてもらいます。同じ文言で `key-message` と `closing` に出します。
- 太字は文の核心だけに使います。
- 問いかけを見出しに使います。例:「〇〇と何が違うの？」
- 変化は `=>` で示します。例:「手作業 => 自動化」
- 日付を添えて、情報の時点を示します。例:「2025/8/7 発表」
- 引用には出典を添えます。「出典:」「引用:」「参考:」のどれかで始めます。
- 自分の憶測には「個人的な予想」「意訳」と書きます。
- 絵文字は装飾に使いません。

## 色

- 地は `surface`、文字は `ink` を基本にします。色は意味があるときだけ足します。
- `alert` は1枚に1か所までにします。
- `zone` は比較の中の注目範囲、`note-fill` は図中の吹き出しに使います。
- `surface-panel` は本筋を外れる補足のスライドに使います。例:「※覚えなくていいよ」
- `tag-bg` と `on-tag` の黒タグで「今ここ」を示します。
- グラフは `data-blue`、`alert`、`data-green` を使い、系列名を線の近くに直接書きます。
- 暗い場面には `<!-- _class: key-message stage -->` のように `stage` を足します。再掲で場面を切り替えるときに使います。
- `human` と `ai` は、生成AIの型（`actor-flow`、`prompt-block`）で人とAIの担当を示すときだけ使います。飾りには使いません。`human` は枠線とアイコン専用で、文字には `human-ink` を使います。

## 文字

- 和文と英数字は `Noto Sans JP`、コードやプロンプトは `Noto Sans Mono` で組みます。
- 見出しは中央揃えの `t-title` です。時代スライドだけ太い `t-title-era` を使います。
- 1枚1メッセージの主文は `t-message` です。
- 本文は `t-body`、第2階層は `t-sub`、説明は `t-caption`、出典は `t-note` です。
- `t-note`（18px）より小さい文字をスライドに置きません。
- 全面画像の一言は `t-display` です。字間の広い `t-brand` は `brand` だけで使います。

## レイアウト

- 左右の余白は `space-8` です。見出しは上から `space-4` の位置に置きます。
- 工程ボックスとスクリーンショットは `radius-0` の角丸なしです。
- 吹き出し、タグ、カードは `radius-sm`、注目範囲は `radius-zone` です。
- 影とグラデーションは使いません。階層は線と面で作ります。
- 動きは使いません。場面の変化は再掲とスライド送りで見せます。
- フォーカスリングが必要な場合は `ink` の 3px 実線にします。

## 画像

- 話の写真やスクリーンショットは、デッキの `images/` に置きます。
- 画像の加工でコラージュを作りません。画面写真は1枚に4点までにします。
- ニュース記事は画面写真でなく `source-cards` で引用します。
- 生成AIの話の時代画像（`assets/Eras`）と章の始まりの画像（`assets/Imagery/evolution-hero.jpg`）は、その話題のときだけ使います。

## 発表者のアイコン

- アイコンは LT 用と同じ `../../design-system/project/assets/Logos/nobisuke-avatar.jpg` を使います。
- 表紙では `gl-author` の中に置き、名前とアカウントを添えます。
- 自己紹介では `![avatar](...)` と書くと、左上に丸く切り抜いて置かれます。
- アイコンを描き直したり、色を変えたりしません。

## ロゴ

- 所属のロゴは任意です。置くときは `![logo](...)` と書くと左上に置かれます。白い地の上に置き、暗い写真の上では白い板に載せます。
- プロトアウトスタジオの講座では `assets/Logos/protout-studio.png` を使います。
- ロゴを描き直したり、色を変えたりしません。

## アイコン（記号）

- Icons の `human.svg`、`robot.svg`、`context-store.svg` は、生成AIの型で使います。
- スライド内では `<i class="gl-icon gl-icon--human"></i>` と `gl-icon--robot` を使うと、周囲の色を引き継ぎます。
- この3つ以外の絵文字やアイコンを足すときは、用途を決めてからこの体系に追加します。
